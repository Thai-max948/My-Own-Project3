# RepFlow Product Specification

## 1. Product Overview

## Product Name
RepFlow

## Vision

RepFlow is a workout application that turns training into a 30-day progression journey.

Instead of only showing exercises, RepFlow helps users answer:

- What should I train today?
- How much should I do?
- Am I actually getting stronger?

The goal is to make fitness training feel like a guided progression system.

---

# 2. Target Users

RepFlow is designed for:

- Beginners who don't know what to train
- Intermediate gym users
- Calisthenics enthusiasts
- People training at home
- People who want a short 30-day challenge

---

# 3. Core Product Loop

The main experience:

Workout
↓
Record Performance
↓
Analyze Progress
↓
Adapt Future Training


The application should help users improve gradually.

---

# 4. Main Features

## User System

Users can:

- Register/login
- Create a profile
- Select fitness goals


## Goal Selection

Users choose:

Goals:
- Build Muscle
- Lose Fat
- Get Stronger
- Learn Calisthenics Skills
- Improve Fitness
- Build Endurance


Training environment:
- Home
- Gym
- Outdoor
- Calisthenics Park


Available time:
- 15 minutes
- 30 minutes
- 45 minutes
- 60+ minutes


---

## Workout System

Users can:

- View today's workout
- Start workout
- Record sets
- Record reps
- Record weight/time
- Save workout history


---

## Exercise Library

Each exercise contains:

- Name
- Muscle groups
- Difficulty
- Equipment
- Instructions
- Common mistakes
- Recommended sets/reps
- Video/GIF demonstration


---

## Progress System

Track:

- Weight
- Reps
- Sets
- Training volume
- Workout duration
- Personal records
- Body measurements
- Skills unlocked


---

## 30-Day Challenge

Users follow progressive challenges.

Example:

Day 1 → Beginner level
Day 15 → Intermediate level
Day 30 → Target achievement


---

# 5. Unique Value

RepFlow is:

Simple:
- Tell users what to train today

Adaptive:
- Adjust difficulty based on performance

Motivating:
- XP
- Streaks
- Achievements
- Challenges


---

# 6. MVP Scope

## Phase 1 - Basic

- Authentication
- User profile
- Goal selection
- Exercise library
- Workout plans
- Workout execution
- Record workout results
- Workout history


## Phase 2 - Progress

- Statistics
- Personal records
- Training streak
- Progress charts
- 30-day challenge


## Phase 3 - Smart System

- Adaptive difficulty
- Personalized workout generation
- Recovery recommendations
- Performance analysis


Important:

Do not build AI recommendation first.

Build the workout data system first.
